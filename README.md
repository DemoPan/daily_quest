# 🧭 探险学堂 · 每日作业闯关打卡系统 (Kids Quest)

> **智慧岛航海记** · 专为家庭双娃打造的游戏化、探险式学习打卡与亲子协同验收系统。  
> 告别催促内耗，把枯燥的日常作业变成一场充满惊喜的航海大冒险！

## 💡 为什么做这个系统？

- **👦 孩子侧（告别被动催促）**：
  - 化身“知识探险家”，每一次完成作业都是一次“关卡攻克”，伴随即时经验值（XP）与金币掉落（🪙）。
  - 拥有属于自己的梦想储蓄罐，用金币兑换真正的自由心愿（游戏时间、免作业特权、美食出游）。
  - 7 天大富翁航海棋盘，让每天的微小积累肉眼可见。
- **👨‍👩‍👧 家长侧（告别内耗纠结）**：
  - 建立明确的规则闭环：**放学自主搞定 ➔ 晚间 8:30 家长极速盖印 ➔ 掉落金币兑现心愿契约**。
  - 支持一键生成适合 A4 纸张打印的纸质学习单与周成长喜报，贴在冰箱或书桌旁，全家共同见证进步。

## 🌟 四大核心功能模块

### 1. 📜 每日作业动态闯关打卡表 (Daily Quest)
- **高辨识度标签体系**：
  - `🏠 回家作业`（暖橙色胶囊）：代表放学后需在家完成的巩固与拓展任务。
  - `🎒 课堂作业`（知识蓝色胶囊）：代表在校内已完成或需查验的作业。
- **双重核验机制**：
  - **孩子「已搞定 ✓」**：圆角弹性卡片复选框，点击点亮翡翠绿并伴随五彩礼花撒花特效。
  - **家长「家长签印 / 已核验 ✓」**：常态为虚线签印章；晚间查验后呈现倾斜金星火漆印章与真实时间戳（如 `⭐ 家长已核验 ✓ 20:15`），并发放对应关卡金币。
- **动态关卡管理**：
  - 行内自由编辑任务要求、课次与练习册页码，即改即存。
  - 一键移除今日不需要的作业条目，动态重算各科关卡与总进度分母。
  - 支持按回家/课堂/待完成多维度快速筛选。

### 2. 🪙 宝藏兑换屋 · 愿望补给站 (Treasure Shop)
- **终极大愿望契约 (Big Goal Card)**：
  - 设置春季学期大愿望（如“乐高机械组 · 环球影城一日游 300 🪙”）。
  - 储蓄进度条、剩余金币差额计算与坚持打卡预计解锁天数预测。
- **即享心愿货架**：
  - 6 款可兑换好礼：`周五免写一项机动作业特权卡`、`多玩30分钟 Switch/乐高时间`、`周末哈根达斯冰淇淋券`、`周末家庭影院选片权+爆米花`、`周末早晨赖床30分钟免催卡`、`自选课外漫画或科学图鉴`。
  - 智能余额校验与即时兑换，生成虚拟卡券存入核销手账。
- **孩子自主心愿发起台 (Wish Submission Station)**：
  - 鼓励家庭民主协商：孩子填写心愿名称与期望金币标价，提交家长 24h 内审批上架。
- **已兑战利品与核销手账 (Redemption Ledger)**：
  - 集中管理已兑换凭证，支持待核销、待核验与已完成状态流转。

### 3. 🗺️ 知识寻宝地图 · 航海探险日志 (Knowledge Adventure Map)
- **7 天大富翁周度航线**：
  - 汉字森林（周一） ➔ 几何山峰（周二） ➔ 语法港湾（周三） ➔ 地理迷宫（周四） ➔ 综合挑战哨站（周五·今日驻扎🚩） ➔ 阅读秘境（周六待解锁银宝箱） ➔ 黄金宝藏岛（周日通关大奖 +100 金币）。
- **学科精力分配雷达**：
  - 统计语文、数学、英语、小四门、课外拓展的用时占比与周学时总计，配有温暖专业的“探险导师每周锦囊”。
- **成就殿堂与习惯勋章**：
  - 点亮“晨读百灵鸟”、“闪电计算王”、“错题清道夫”、“书海潜水员”，以及进度解锁型“月度探险领航者（19/30天）”。

### 4. 🛡️ 家长 8:30 极速核验台 (Parent Bench)
- **晚间 8:30 一键全科盖印验收**：
  - 家长一键给今晚所有孩子已搞定的作业盖上金色火漆印章，批量掉落金币并奏响通关庆祝号角。
- **孩子自主心愿审批**：
  - 对孩子在兑换屋提交的心愿申请进行“同意上架”或“价格协商”。
- **表现优异奖励金币投放**：
  - 针对主动整理书桌、攻克难题耐心思考等好习惯即时奖励 +5 ~ +30 🪙。

## 🛠️ 辅助功能与体验亮点

1. **双娃角色无缝切换**：
   - 顶栏一键切换 `🦁 大宝 (六年级 · 知识探险家)` 与 `🐰 二宝 (二年级 · 快乐小学徒)`，双套完全独立的数据池、年级适龄任务、航海地图与储蓄罐。
2. **番茄钟专注计时舱 (Focus Timer)**：
   - 支持 10/15/20/25/30 分钟环形进度倒计时、柔和滴答声与提前攻克打卡奖励。
3. **A4 纸质单据打印排版**：
   - 适配 `@media print` 标准 A4 纸张规范。
   - 一键打印「今日作业打卡学习单」（含学生自评签名区与家长签印区）。
   - 一键打印「周成长探险喜报」（适合贴在冰箱或书桌旁的全家表彰海报）。
4. **轻拟物触感与音效 (Playful Neo-Tactile)**：
   - Squishy 物理下压按钮（`shadow-neo-*` + `active:translate-y-1`）。
   - 原生 Web Audio API 声音合成器（点击、金币碰撞、印章盖压、通关号角），零外部音频文件加载。
5. **本地离线持久化**：
   - 数据自动存入浏览器 LocalStorage，免去复杂后端搭建，刷新或关机数据永不丢失。

## 🚀 快速启动指南

### 依赖环境
- Node.js >= 16 (推荐 Node.js 18+)
- npm 或 pnpm / yarn

### 运行步骤

```bash
# 1. 克隆代码仓库
git clone git@github.com:DemoPan/daily_quest.git
cd daily_quest

# 2. 安装依赖包
npm install

# 3. 启动本地开发服务
npm run dev

# 4. 生产环境打包构建
npm run build
```

启动后在浏览器打开：`http://localhost:3000/` 即可体验。
